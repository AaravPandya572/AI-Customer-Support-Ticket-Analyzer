# Exploratory Data Analysis (EDA) Notes

**1. Dataset Size**
- The dataset contains 2,811,774 rows and 7 columns.

**2. Missing Values**
- Are there missing values? Yes.
- The columns with the missing values are `response_tweet_id` (1,040,629 missing) and `in_response_to_tweet_id` (794,335 missing). 

**3. Inbound vs. Outbound Ratio**
- Number of messages sent by customers (inbound = True): 1,537,843
- Number of messages sent by companies (inbound = False): 1,273,931
